# CLAUDE.md

Standing instructions for Claude Code in this repository. Follow them in every session without being reminded.

## Git workflow

Always work directly on the `main` branch. Do not create feature branches and do not open pull requests, because nothing should ever need to be merged. Commit on `main` and push straight to `origin main`. If a session starts on any other branch, switch to `main` first and do all work there.

## Writing style

This applies to everything drafted in prose, for example paper text, slides, notes, and summaries. Write plain sentences that end with periods. Do not break or join sentences with dashes (`-` or `—`), semicolons (`;`), or colons (`:`). Split the thought into separate short sentences instead. This rule is about prose only, so such characters remain fine inside code, file paths, and LaTeX commands.
